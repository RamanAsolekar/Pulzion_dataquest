## QA Data

```python
from datasets import load_dataset
peerqa_qa = load_dataset(
    "UKPLab/PeerQA",
    "qa",
    trust_remote_code=True
)
```

The resulting dataset has the following columns:

* `paper_id` (`str`): An identifier the the paper that this question is about. It it built like this: `venue/conference/id`, e.g. `openreview/ICLR-2022-conf/_X90SIKbHa`.
* `question_id` (`str`): An identifier for the question (hash of the question text).
* `question` (`str`): The question text.
* `raw_answer_evidence` (`list[str]`): The evidence that the authors have highlighted in the PDF to answer the question.
* `answer_evidence_sent` (`list[str]`): The evidence that the authors have highlighted in the PDF to answer the question, split into sentences.
* `answer_evidence_mapped` (`dict[str, Union[list[str], list[list[int]]]`): The evidence that the authors have highlighted in the PDF to answer the question that could be mapped to extracted text from the PDF. Note that not all raw evidence could be mapped because some text, unfortunately, gets lost during text extraction from PDF. The dictionary contains the following keys:
  * `sentence` (`list[str]`): The evidence that could be mapped to extracted text from the PDF, split into sentences.
  * `idx` (`list[list[int]]`): The indices of the extracted text that correspond to the evidence sentences.
* `answer_free_form` (`str`): The free-form answer to the question as provided by the authors.
* `answer_free_form_augmented` (`str`): The free-form answer to the question generated by GPT-4o based on the evidence (if available) and the `answer_free_form` answer.
* `answerable` (`bool`): Whether the question is answerable as determined by the authors.
* `answerable_mapped` (`bool`): Whether the question is answerable as determined by the authors or if none of the raw evidence could be mapped to extracted text from the PDF.

## Paper Data

The extracated text from the papers can be loaded like this:

```python
from datasets import load_dataset
peerqa_papers = load_dataset(
    "UKPLab/PeerQA", 
    "papers-all", # or "papers" to only download papers with permissable licenses 
    trust_remote_code=True
)
```

Note that `papers-all`, downloads papers from OpenReview and processes them using GROBID. We cannot provide the raw PDFs due to copyright reasons. If you want to only use the papers with permissable licenses, you can use the `papers` dataset instead. The code uses the GROBID service hosted on huggingface spaces at https://timbmg-peerqa-grobid-0-8-0.hf.space. In case it is not working, double check that the service did not go to sleep. The code also supports using a local GROBID service by setting the `PEERQA_GROBID_SERVER` environment variable. To run GROBID locally, set `PEERQA_GROBID_SERVER` to `http://localhost:8070` and use the following docker command:

```bash
docker run --rm -p 8070:8070 lfoppiano/grobid:0.8.0
```

The resulting dataset has the following columns:

* `paper_id` (`str`): An identifier the the paper that this question is about. It it built like this: `venue/conference/id`, e.g. `openreview/ICLR-2022-conf/_X90SIKbHa`.
* `idx` (`int`): A running index for the extracted text.
* `pidx` (`int`): The paragraph index.
* `sidx` (`int`): The sentence index.
* `type` (`str`): The type of the extracted text, e.g. 'title', 'sentence', 'table', 'figure'.
* `content` (`str`): The extracted text.
* `last_heading` (`Optional[str]`): The last heading before the extracted text. Omitted in case of `table` or `figure`.

## QRels

The qrels file for paragraph or sentence retrieval can be loaded like this:

```python
from datasets import load_dataset
peerqa_qrels = load_dataset(
    "UKPLab/PeerQA", 
    "qrels-sentences", # or  "qrels-sentences-all", "qrels-paragraphs", "qrels-paragraphs-all"
    trust_remote_code=True
)
```

Similar to the papers, the `qrels-sentences-all` and `qrels-paragraphs-all` datasets download the qrels files for all papers, while the `qrels-sentences` and `qrels-paragraphs` datasets only download the qrels files for the papers that have permissable licenses. Note that before loading the `*-all` qrels file, the `papers-all` dataset has to be loaded in order to download and process the OpenReview papers.

The resulting dataset has the following columns:

* `question_id` (`str`): An identifier for the question (hash of the question text).
* `idx` (`str`): The index of the relevant paragraph or sentence. If the dataset is `qrels-sentences`, the index is in the format `paragraph_idx/sentence_idx`. If the dataset is `qrels-paragraphs`, the index is the paragraph index.
* `relevance` (`int`): The relevance of the paragraph or sentence to the question (always `1`).
